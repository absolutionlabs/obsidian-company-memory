# Obsidian Company Memory — v1.2.0

First formal GitHub Release. Three Cowork-installable skill bundles.

## Install (Cowork)

Cowork's upload-skill dialog accepts `.zip` files containing a `SKILL.md` at the root. Download each zip below and upload via **Cowork → Skills → Upload skill → drag-drop**. Three uploads total.

| Skill | Download | What it does |
|---|---|---|
| `obsidian-company-memory` | [obsidian-company-memory-v1.2.0.zip](https://github.com/absolutionlabs/obsidian-company-memory/releases/download/v1.2.0/obsidian-company-memory-v1.2.0.zip) | The main install skill. Scaffolds a working Obsidian vault for a single company, ~25 min. |
| `open-obsidian-project` | [open-obsidian-project-v1.2.0.zip](https://github.com/absolutionlabs/obsidian-company-memory/releases/download/v1.2.0/open-obsidian-project-v1.2.0.zip) | Companion: scaffold a new project against your vault. |
| `close-obsidian-project` | [close-obsidian-project-v1.2.0.zip](https://github.com/absolutionlabs/obsidian-company-memory/releases/download/v1.2.0/close-obsidian-project-v1.2.0.zip) | Companion: run the session-close protocol against your vault. |

Suggested upload order: companions first (small, low blast radius), then the main install skill last.

## Install (Claude Code)

Code-side native install is not yet wired through GitHub Releases. For now, clone the repo and copy SKILL.md into `~/.claude/skills/obsidian-company-memory/` (and the same for each companion under `companion-skills/`). A `.claude-plugin/marketplace.json` for the `/plugin marketplace add absolutionlabs/obsidian-company-memory` path is on the v1.3.0 backlog.

## What's in each zip

- `obsidian-company-memory-v1.2.0.zip` (31 KB) — `SKILL.md` + `templates/` (21 vault-scaffold files: SCHEMA, CONTEXT, index, log, HOW-TO-USE-THIS, starter Operating Principles, page templates, `.obsidian/` config defaults, `_meta/expectations.yml`, and project session-stub templates for Cowork/Code/Codex/opencode).
- `open-obsidian-project-v1.2.0.zip` (3.7 KB) — `SKILL.md` only. Self-contained procedure; no external dependencies once a v1.2.0 vault exists.
- `close-obsidian-project-v1.2.0.zip` (3.5 KB) — `SKILL.md` only. Self-contained procedure.

## What this is NOT

- **Not a Cowork marketplace listing.** These are user-uploaded skills, installed via `Upload skill` not via `claude.com/plugins`. The skills will show in your Cowork skills list under whatever namespace Cowork assigns to user-uploaded skills (likely not the `anthropic-skills:` prefix).
- **Not telemetry-instrumented.** v1.2.0 removed the install-ping that earlier internal builds shipped. The skills never phone home.
