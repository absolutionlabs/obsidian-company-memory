# Obsidian Company Memory — v1.2.1 (first public release)

A control system for AI-assisted company memory, distributed as three skill zips you upload into your AI tool. About 25 minutes from download to a working Obsidian vault that every future AI session reads first.

## What this is

Not an Obsidian template. The folder structure is the rendering layer; the bespoke prompts, rulebooks, and operating principles inside it are the product. A small set of files governs how every AI session interacts with the vault: it reads `SCHEMA.md` first, follows the Ingest / Query / Lint procedure, and writes the result back to an audit trail. You run a one-off install. From then on, your company's knowledge accumulates as a by-product of normal AI-assisted work — not as a wiki you have to maintain on the side.

Built from the same patterns we use to run our own client engagements at Absolution Labs.

## Install — three zips, three uploads

| Skill | Download |
|---|---|
| Main install skill (scaffolds the vault) | [obsidian-company-memory-v1.2.1.zip](https://github.com/absolutionlabs/obsidian-company-memory/releases/download/v1.2.1/obsidian-company-memory-v1.2.1.zip) |
| Companion: scaffold a new project against your vault | [open-obsidian-project-v1.2.1.zip](https://github.com/absolutionlabs/obsidian-company-memory/releases/download/v1.2.1/open-obsidian-project-v1.2.1.zip) |
| Companion: run the session-close protocol | [close-obsidian-project-v1.2.1.zip](https://github.com/absolutionlabs/obsidian-company-memory/releases/download/v1.2.1/close-obsidian-project-v1.2.1.zip) |

**Cowork:** drag-drop each into **Skills → Upload skill** (companions first, main last). Then say *"Set up my Obsidian company memory."*

**Claude Code:** `git clone` the repo and copy the three skill folders into `~/.claude/skills/`. The native `/plugin marketplace add` path is on the roadmap.

**Codex / opencode:** unzip each, append the `SKILL.md` body to your home `AGENTS.md` under a Custom skills section.

Full install instructions: [README.md](https://github.com/absolutionlabs/obsidian-company-memory/blob/main/README.md). Step-by-step reading version of what happens during install: [docs/install-walkthrough.md](https://github.com/absolutionlabs/obsidian-company-memory/blob/main/docs/install-walkthrough.md).
