# Obsidian Company Memory — v1.2.1

Two user-visible changes + a docs sweep.

## What changed

### 1. Compliance gate goes from 3 boxes to 2

Earlier versions asked you to tick three boxes before scaffolding. The third was:

> *I understand this vault will be a record of facts and decisions about my company. Absolution Labs LTD has no access to its contents at any point. The skill does not collect telemetry and does not phone home at install time or afterwards.*

We cut it. **Confirmations should be about your commitments, not our behaviour.** Asking you to consent to a fact about what *we* do read as CYA theatre and weakened the trust signal of the other two boxes. The fact is now stated as a one-line passive statement above the gate (and in [DISCLAIMERS.md](https://github.com/absolutionlabs/obsidian-company-memory/blob/main/DISCLAIMERS.md) in full).

You now confirm two things, both about your setup:

1. The folder is yours to write to (no other party's data already inside).
2. Your cloud sync provider is permitted for the content you intend to store (DPA awareness).

### 2. Install instructions updated to match Cowork's actual install path

v1.2.0 told users to paste a `plugin.json` URL into Cowork. **That isn't how Cowork installs skills** — Cowork's Upload-skill UI takes `.zip` / `.skill` / `.md` files. We verified this empirically by attempting the v1.2.0 install on a second laptop; the existing README told users to follow a path that doesn't exist.

v1.2.1's install path:

- **Cowork:** download three zips from this Release, upload via **Skills → Upload skill** (drag-drop, one at a time).
- **Claude Code:** clone the repo and copy the three skills into `~/.claude/skills/`. Native `claude plugin marketplace add` is queued for v1.3.0 (needs `.claude-plugin/marketplace.json` at the repo root, not yet shipped).
- **Codex / opencode:** download the zips, unzip, append each `SKILL.md` body to your AGENTS.md under a "Custom skills" section.

Full install instructions: [README.md](https://github.com/absolutionlabs/obsidian-company-memory/blob/main/README.md).

## Upgrading from v1.2.0

In Cowork: uninstall the v1.2.0 versions of all three skills first, then upload the v1.2.1 zips. The vault data you've scaffolded (if any) is untouched — only the skills change.

In Claude Code: `rm -rf` the three skill folders under `~/.claude/skills/`, then re-clone and re-copy from the v1.2.1 commit.

## Behind the scenes

- `scripts/build_cowork_zips.py` automates spec-compliant zip building (forward-slash paths, SKILL.md at root, stages outside Dropbox to dodge sync-lock races on Windows). Replaces the manual PowerShell approach which silently emitted backslash paths Cowork rejects.
- The repo's `plugin.json` files (root + both companions), `MANIFESTS.md`, and `scripts/lint_manifest.py` are preserved as historical record of the discarded URL-paste design, each carrying a `_deprecated` header explaining the current install paradigm. Not deleted, per our documentation-preservation discipline.
